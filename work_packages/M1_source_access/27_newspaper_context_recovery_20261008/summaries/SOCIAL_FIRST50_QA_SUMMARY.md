# First publicly sourced social Q&A cohort

Snapshot: 8 October 2026, 20:45:41 AEST. This frozen first cohort contains **50 native questions** from Sustainable Living Stack Exchange. It demonstrates a documented anonymous public API, saved original responses, structural body extraction and recorded immediate durable Load into the independent social store. It is a **global specialist Q&A** frame, not a regional forum sample or completion of the social task.

The coordinator matched all 50 persistent/native IDs, source URLs, native creation dates, whole-body hashes and the original raw-response digest against the first Load receipt. These questions were created on **29–30 January 2013**; an early chronological API page does not establish full January, site-era or 1988–2026 coverage. Retrieval on 8 October is separate from publication/edit times and does not certify the body's historical version. No live database read or older-corpus audit was repeated.

The extractor's separate-native-namespace correction must preserve these 50 existing IDs while distinguishing new questions, answers and comments and their actual parent/thread relations. Forum thread containers, newspaper articles and reply-page snapshots are not substitute post units. Country and author-role claims are not inferred from the host or topic.

[SOCIAL_FIRST50_QA_IDS.csv](SOCIAL_FIRST50_QA_IDS.csv) and [SOCIAL_FIRST50_QA_MANIFEST.json](SOCIAL_FIRST50_QA_MANIFEST.json) contain the finalized cohort metadata and evidence hashes. Original API text, local store and runtime receipts remain local. The official [public questions API](https://api.stackexchange.com/docs/questions) and [license guidance](https://stackoverflow.com/help/licensing) support route and license interpretation. No full text is published in this package.

The ongoing task continues forum/public-platform source evaluation and permitted native-content ELT, with five regional source-opportunity frames and explicit actual access/history gaps. This first cohort cannot substitute for those deliverables or a general-public population sample. Current topic or fear labels are neither computed nor used for retention.
