existing bytes. It resumed within the original 8 GB social envelope and stopped
at the unchanged original deadline. A narrow unindexed final metadata-count
lookup was corrected during closeout, without a new database migration or old
body audit. Nine inherited date/era cases remain unresolved.

The later authorized successor uses 15 GB cumulative social inside 30 GB shared
and ends at 19:43:58 AEST. It prioritizes earlier source eras and broader
conventional newspaper/general-public frames; it is a separate live run and is
not part of this closed delivery. There is no article/request/source count or
coverage-score completion rule, no yearly-share target, no semantic inclusion
filter and no deletion. Physical/source protections remain in force.

## Published files and limits

- `newspaper/` contains final article/source/month/provenance/raw manifests,
  source admission limits, bug evidence and the collection report.
- `social/main/` contains the first closed report, aggregate tables and original
  delivery/implementation manifests. Large compressed native entity exports
  remain local at the exact paths and hashes in that original delivery manifest.
- `social/append/` contains the separate final delta reports/tables/manifests.
- `implementation/` subdirectories and `social/append_implementation/` preserve
  selected closed acquisition, extraction, validation and export code. They are
  implementation records requiring local owner-bound controls to execute, not
  a live acquisition release. Main social implementation hashes match the
  original accepted manifest.
- [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json) maps every selected copy
  to its preserved original local file and digest. Runtime leases, owner
  dispatch state, queues, checkpoints and individual receipts remain local.
