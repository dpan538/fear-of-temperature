# Public social and forum acquisition

This is a separate social carrier stream within *Fear of Temperature*. Its unit is one native authored forum post/reply, question, answer, comment or platform post. A discussion topic, API page, repost wrapper, preview or newspaper article is not another authored post. Source/public accessibility, local research retention, content licensing and redistribution are recorded independently. The fixed native publication interval is **1988-01-01 through 2026-09-21**; September is partial. Retrieval in October does not move the endpoint or certify a historical body version.

`code/social_elt.py` provides bounded anonymous transport, lossless raw preservation, structural cleanup, native adapters and immediate version-preserving SQLite Load. `code/collect_wave.py` implements the source-native forum and dated Q&A frame; `code/collect_platforms.py` implements the limited regional timeline and official-account frame. `code/closeout.py` verifies this changed tranche once and exports consolidated metadata. Runtime owner/release/lease bindings, cursor/frame inputs, receipts, raw objects and SQLite are local under `worker/` and coordinator-owned `control/`. They are required to run the code and are deliberately not publication deliverables. A new execution must have its own bounded release; these scripts do not grant an automatic successor.

The operational boundary follows the repository's [public-interface and native-unit contract](../../../../docs/acquisition/SOURCE_INTERFACE_AND_UNIT_CONTRACT.md). Newspaper, government and reviewer stores are outside this implementation. No source is selected, rejected or scored by climate relevance, fear words, emotion, anticipated harm, embeddings or distribution-uniformity measures. Topic/affect validation remains later work.

The wave first saved 50 whole questions, then corrected the native identity namespace after a focused review. Questions/answers share Stack Exchange's native `post` namespace; comments use `comment`. The 50 established persistent IDs were preserved through explicit native mappings. The real question 1/comment 1 collision was independently retained. URL slug changes enter an alias table while the first canonical URL and persistent ID remain. Historical adapter aliases remain explicitly deprecated metadata, not additional native posts.

The actual source frame comprises a chronological Python forum-index prefix, ten associated topic containers with complete native posts, the first 30 creation-ordered questions per year on each of two specialist Q&A sites and bounded answers/comments to the first 50 selected questions. Truncated index previews remain raw/index evidence. Four Mastodon snapshots use documented local public timelines and a primary-implementation-derived `max_id` cursor near the fixed endpoint; returned `created_at`, rather than the cursor, determines eligibility. Three Bluesky author-feed pages concern its official `bsky.app` account and retain institutional expression separately. These are bounded source opportunities, not random samples, complete archives or national opinion estimates.

Every regional stratum has three planned source parents: two forum candidates plus one explicitly regional Mastodon community. Failed/blocked sources retain their opportunities; effort is not reassigned to make counts equal. Several forum geographic assignments remain provisional pending primary evidence. Mastodon community location/description never assigns an author's country. Global Python, Earth Science and Sustainable Living communities remain supplementary specialist frames.

Stack Exchange uses native returned revision-specific CC BY-SA where available; absent exact versions stay unknown within the supported licence family. Python Discussions' site grant is **CC BY-NC-SA 3.0**, a restricted noncommercial grant, not open data. The four Mastodon instances and Bluesky are bounded documented public-read/local snapshot routes with source-specific use rationale; their authors do not receive an invented CC licence. Full text/raw remain local. Mastodon NZ explicitly requires author permission for reuse outside the Fediverse. Mumsnet prohibits unlicensed copying/scraping. Other forum access/API/retention uncertainty, approval-only Reddit/Meta routes and missing YouTube credentials remain named gaps. The OSM map licence is not evidence of forum-post rights; Discourse Meta is excluded under its automation prohibition.

Transport charges attempts before dispatch, preserves source stops and caches saved responses for restart. All formal operations revalidate the digest-bound owner release/deadline, take the shared heavy-I/O lock, read actual active leases and test physical, lifetime-media and social allocation headroom. A lifetime social mutex prevents a second writer. Bounds remain 200 charged requests including probes, 2,000 distinct returned native objects, 128 MiB within the shared 5 GB, 2 MiB raw objects, two-second host spacing, server backoff, 15 GiB floor and 48 MiB recovery headroom. No accounts, keys, messages or private/undocumented endpoints are used.

`summaries/` contains the finalized native/version and response manifests, API-return and source-quality tables, source registry, identity/URL mappings, source-era calendar, regional opportunity ledger and collection report. These are metadata/link/hash deliverables. Raw/full-text redistribution is not authorized by producing the tables. Later reuse of platform snapshots requires deletion/edit reconciliation and its own source-use review; a publicly deployed mirror or training service is outside this scope.
