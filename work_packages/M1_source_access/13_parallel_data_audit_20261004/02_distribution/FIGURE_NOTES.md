# Figure contract and QA

Python/Matplotlib was the saved plotting preference and the language of the existing project atlas. Both new figures are landscape, single-panel report figures with editable SVG/PDF text and 320-dpi PNG previews. The project atlas palette and type hierarchy were reused. Source data are local CSVs generated by `build_distribution.py`.

| Figure | Core conclusion and evidence | Archetype |
|---|---|---|
| `figure_01_monthly_intensity` | Monthly parent/Work intensity is concentrated in source-specific periods and includes calendar/source-frame gaps. Each row is scaled to its own 95th percentile; colour is not a cross-source rate. | Single-panel quantitative heatmap |
| `figure_02_count_units` | Parent/Work totals, linked objects, saved versions and extraction segments are different units; shared pages, attachments and download depth have different effects. | Single-panel quantitative dot plot |

Both final PNGs were visually inspected at rendered size for typography, labels, legend and spacing. The source preflight reports **17 PASS, 4 WARN, 0 FAIL**. Its warnings are deliberate report choices: PNG rather than a journal TIFF, 320 rather than 600 dpi, wide landscape dimensions, and a log x-axis whose plotted ratios are strictly positive. The PDF text audits found minimum text sizes **7.6 pt** and **7.4 pt**, above the 5-pt floor. The collision audit could not run because PyMuPDF is unavailable in the project environment; no collision-validation pass is claimed. These figures are internal audit evidence, not submission-ready journal panels.
