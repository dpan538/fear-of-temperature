# 巴黎协定事件窗口：数据准备度与小型试点摘要

> **后续更正（2026-09-27 14:19 UTC）：** [第二轮核查](round2_december_2015/SUMMARY_zh.md)以 `opened_at` 的已发表请愿为公众/公民主口径。固定 `q=climate` 查询中，2015-11 已发表请愿为 **0**；下文所说“11 月至次年 1 月三角色重叠”不再适用于主口径。Guardian 2015-12 已得到 396 篇当前档案候选文章的整月框，但仅核验四篇正文。

快照：2026-09-27 13:20:51 UTC（网络试点）；政府计数沿用此前 10:53 UTC 汇总及 12:36 UTC EPA 补桥台账。事件窗口为 2013-12 至 2017-12，共 49 个月。主交付是 [49×3 准备度表](paris_month_role_readiness_49x3.csv)、[英文报告](REPORT.md)和[字段字典](FIELD_DICTIONARY.md)。

- 政府层 49/49 月有至少一份已存正文，但整月“升温相关”与“恐惧相关”数量均未审核。EPA 固定 `final_rule` 来源在 49 月有 2,304 份合格元数据，其中只取得 10 个月的 125 份正文；2015-04/05 分别完整取得 63/38 份。不能把 49 月政府存在误认为 EPA 连续全文序列，也不能合并英国答复与美国法规原始数量作趋势。
- 政府诊断样本 23 个独立 parent（英国政策 3、答复 11、EPA 9），人工核对标题、正文片段、附件、原日期、版本/片段映射与 EPA 勘误/直接终局规则边界。5 个与气候/升温议题相关；未核实到明确恐惧表达。样本特意包含标题候选与对照，不能推算总体比例。
- 媒体以 Guardian 三个固定日期档案页为抽样框，标题卡去重后为 22、17、7 篇非视频文章；检查 4 篇有发布日期与正文的独立文章，其中 3 篇与气候有关。这是按日试点，并无整月分母。Guardian 试用 API 返回 401，后续大规模正文获取需解决访问和使用条件。
- 公众以英国议会 2015–2017 历史请愿 `q=climate` 为有限检索框：8 页 179 个位置、去重后 177 个 ID。2015-11 至 2016-01 的 21 条中，13 条已发表、8 条被拒绝；14 条经审阅与气候相关，6 条含预期气候损害线索，但没有核实到明确恐惧表达。被拒请愿不能按创建日期直接当作公开讨论；政府答复不算公众文本。表中的两个公众“零”仅表示此固定关键词查询在该月没有命中，不是公众讨论或气候相关性的零。

2015-11 至 2016-01 是目前观察到的最小三角色试点重叠区间，**尚不构成可比较的月度面板**。下一步优先建立整月媒体采样框及正文访问规则、明确请愿“已发表/全部提交”纳入标准和月分母，再对政府同文种做更多来源感知清洗与相关性复核。本次不修改 proposal、不估计 RQ1/RQ2 的先后或事件效应，RQ3 暂缓。
