# 第二轮有界核查摘要

截止 2026-09-27 14:19 UTC；详见[英文简报](BRIEF.md)与[更新后的 49×3 表](paris_month_role_readiness_49x3_round2.csv)。

- Guardian 2015-12 的 31 个环境栏目每日档案页均可访问；排除视频并按文章 URL 去重后，有 **396 个**候选 article parent。396/396 文章页可访问，且原始发布时间均落在 2015-12 UTC；未发现日内分页。另有 3 篇按预定规则抽查了正文，连同上一轮 1 篇，**仅 4 篇正文已核验可读**。396 是“当前档案规则下的整月候选分母”，不是整月气候相关或恐惧相关篇数，也不能保证 2015 年当时页面版本与今天相同。
- 英国议会历史请愿 `q=climate` 的 177 个独立 ID 中，**77 个有 `opened_at` 的已发表请愿**进入公众/公民渠道主口径，**100 个被拒提交**仅留在 `created_at` 对照。2015-11、2015-12、2016-01 的主口径分别是 **0、8、5**；全部提交口径分别是 **4、14、3**。两条 11 月创建的请愿到 12 月才发表，两条 12 月创建的请愿到次年 1 月才发表。因此上一轮“11 月已有已发表公众文本”的三角色重叠说法不再成立。11 月的零只限于这个关键词查询，绝非公众气候讨论为零。
- 官方“已发表请愿”CSV 没有日期；JSON 有 `opened_at`，但每页 25 条、共 438 页。本轮没有全量遍历，故**尚无全部合格请愿的月分母**，不可计算公众月度气候/恐惧比例。`climate/warming topic`、`anticipated harm cue`、`explicit fear expression` 三种标签仍分开；预期损害不能自动算情绪。

下一步判断：Guardian **可进入有界月度候选清单阶段**，仍不可作为现成恐惧时间序列；议会请愿**可作为按发表日期计的公民请愿渠道**，但不能代表整体公众。若 Guardian 后续访问或使用条件不成立，可对 Carbon Brief 做最小的日期档案及权限核查；其 API 此次返回 403，目前不能作为已验证替代。没有运行 RQ1/RQ2 统计、全库向量化，亦未改 proposal 或正式数据库。
