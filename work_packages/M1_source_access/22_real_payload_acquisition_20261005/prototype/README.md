# Round 22 public payload prototype

This local successor repairs the earlier whole-source stop and per-field coordinator-release coupling. The saved round22 authorisation permits requests after targeted offline validation, registered input/code/policy/frame digests and a fresh storage preflight. A real publisher denial remains binding; a transport/path failure stops its declared route family and does not prove an entire publisher is restricted. Historical packages are read-only. No formal government database is opened.

From the repository root, `python3 -B work_packages/M1_source_access/22_real_payload_acquisition_20261005/prototype/run.py budget` checks the original reserves and floor. `preflight` records digests, and `initial-discovery` attempts the declared independent initial routes. The runtime needs Python, requests and BeautifulSoup already installed in this workspace; nothing is installed by this round.

Further `request` operations require a declared source, HTTPS URL, purpose and route family. Robots are saved or reused as a specifically dated observation. At most20 metadata/discovery requests per candidate, two redirects per media request, two seconds between source requests and one initial request per body are allowed. Explicit denials and Retry-After stop a publisher. There are no automatic retries. Government redirects are recorded and stopped without following.

Use `freeze-frame --source SOURCE --month YYYY-MM --route FAMILY --input FILE` with actual saved candidates/evidence/notes. The frame is immutable, selects the first five by publication day/native URL, and retains unknown monthly denominator/inclusion probability. `inspect` parses a saved raw request with a verified source-specific DOM selector. `certify` requires actual start/end lines and explicit inspected identity, publication, source/edition, no-preview/no-missing-continuation and rights facts. JSONLD alone never certifies a body. No topic, emotion or length criterion selects an article. The raw, later-retrieved version and independent publication unit remain separate.

`government-prepare` binds the preserved current406 and first ten never-attempted selected Items in the existing frozen order. `government-execute` runs only this11-target sequence, stops on its first failure, and writes owner events here rather than the phase1 isolated auditor log. It must follow the initial media pass and a passing preflight. A saved PDF is a candidate Item, not a verified complete Work or new source original.

The24 targeted tests run with `python3 -B -m unittest discover -s work_packages/M1_source_access/22_real_payload_acquisition_20261005/prototype -p 'test_*.py' -v`. Synthetic request outputs are confined to temporary directories and deleted; actual package counts never include them. Tests establish bounded code behaviour, not online access, body acquisition, OCR readiness or historical-version equivalence.

Network operations stop at the scope deadline. A failed budget must not be worked around by reducing the original reserves, deleting old evidence or changing the floor. Save the blockage and continue independent offline packaging.

For inspected exceptions, `inspect` accepts `--boundary-spec FILE`, `--source-timezone ZONE --observed-local-day YYYY-MM-DD`, or `--source-date-evidence FILE`. Saved selectors/date evidence are in each local parsed receipt. `review_saved.py` applies only the explicit inspected IDs listed for this round; it refuses unknown targets. Local fulltext and detailed passage checks are ignored by Git. The final network-closure marker prevents further requests, including before the hard deadline.

`package_saved.py` builds compact local manifests from already saved request/inspection receipts. It reads only the accepted frozen government metadata ledger for previous raw hashes and never opens old government raw or a database. `media.dated_search_inventory` reproduces the corrected discovery metadata inventory; it cannot revise a frozen frame or certify a body.

`validate_package.py` verifies the final changed-tranche manifests and caps using saved new-object hash receipts and the30 derived body hashes. It does not read old government raw. The original coordinator registration is read-only and remains unstaged; COORDINATION_READ_ONLY_RECEIPT.json supports offline reproduction when the original local file is absent.
