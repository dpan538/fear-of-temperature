# Git 与本地采集材料的边界

Git保存采集/校验代码、冻结来源规则、字段字典、紧凑报告、图表、请求状态和hash收据。原始语料、运行数据库、大体量逐行清单、重复中间快照、临时目录、下载锁、课程原始材料和本地依赖环境留在原位置，不删除，也不因本次提交重新采集或清洗。

`.gitignore`明确列出当前大体量本地文件及原始API/网页/PDF路径。提交报告中的相对路径和原hash仍指向这些本地材料；仅克隆Git仓库不等于取得完整语料。恢复或复核时应先取得相应已冻结输入，再遵循原检查点、访问停止及单一writer要求。

Round20保留一份2706-byte的公开robots快照，供现有断网整链夹具读取；它是访问规则证据，不是媒体文章。真实媒体正文仍为0，模拟样本与实际数据始终分开。

独立分布评估器的源码、隐藏夹具、解密凭据和加密包保持仓库之外。本仓库仅记录公共封存/验收收据，不在本次Git整理中解封、重新执行或分发。

本次提交使用当前真实提交时间；文件中较早的采集/报告日期保持历史意义。不回填提交日期，不修改旧提交。
