# Research documentation

This directory contains or will contain the project’s evidence-backed research documentation, including:

- historical lexical research;
- anchor validation;
- source inventories;
- semantic validation;
- corpus design notes;
- research freeze manifests.

Reports should be added only when the corresponding research artifact is available. This foundation does not invent or stand in for reports that have not been copied into the repository.

The current research design is maintained in the local `proposal/` tree, whose publication scope is reviewed separately because this repository is public. The rebuilt Python/NLP workspace is validated on explicitly synthetic data only; see [`../WORKSPACE_VALIDATION.md`](../WORKSPACE_VALIDATION.md). The earlier quantitative validation under `fear-temperature/` remains a preserved provisional baseline rather than the current proposal's empirical result.
