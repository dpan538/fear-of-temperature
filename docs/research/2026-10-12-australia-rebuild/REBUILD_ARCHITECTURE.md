## Independent identity, versions and lineage

[schema.sql](schema.sql) is executable SQLite DDL for small conformance fixtures. It specifies a logical contract that can later be bound to a measured production backend; it does not choose a production host or run a migration. [adapter_contract.py](adapter_contract.py) uses only Python's standard library and explicitly accepts projections into **in-memory SQLite only**. There is no network function or file-backed database target. The 1 MiB CLI input bound is fixture safety, not a corpus, source, article or passage quota.

| Layer | Contract and preservation rule |
|---|---|
| Archive evidence | `archive_snapshots` and `archive_records` preserve snapshot/path, old ID/version, locator, recorded hash and its basis. A table locator or declared sidecar is valid evidence; neither requires wholesale body copying. |
| Source facts | Stable `sources`; versioned `source_assertions` with Australian institution/publisher/community evidence, genre, as-of and applicability. Unknown historical author geography stays unknown. |
| Source/parent relations | `source_relations` distinguishes legal publisher, title/edition, acquisition/API parent, archival reproduction, community, author account and evidenced named person. A source ID is not automatically an independent parent. |
| Rights | `rights_assertions` keeps public access, local retention, internal analysis, licence, conditions and redistribution separate. Reachability or open software is not a post-text licence. |
| Native unit | `units` uses source + typed namespace + native ID. Stable new IDs are full SHA-256 keys over those components. Missing identity yields a visibly proposed archive-based candidate key, never a verified native key. |
| Metadata | `metadata_versions` preserves original publication value/precision/evidence, date bounds, native identity/author evidence, retrieval, extraction, content-version and report times. Later retrieval does not establish historical body equality. |
| Body/version | `content_versions` distinguishes exact original native-string hash, raw/source-byte hash and their bases. `text_representations` gives original, structurally derived or OCR text separate immutable IDs/hashes. No identical-body rule merges independent works. |
| Assembly | `content_source_parts` preserves ordered pages, columns, attachments, JSON fields or XML nodes, their locators/hashes/spans and evidence. These parts do not become independent newspaper articles. |
| Native relations | `unit_relations` preserves sitting, procedural unit, utterance, paragraph order, thread/reply, repost, remote quotation, attachment, syndication/mirror and explicit identity resolution. Unloaded parent targets retain typed native references; they are not fabricated local parents. |
| Speaker/role | `speaker_role_assertions` separates speaker, party, executive office, government/opposition and quoted holder, with valid-time bounds and evidence. No party-to-executive inference is implemented. |
| Admission | Seven independent checks and an append-only `admission_ledger`; a separate `archive_to_new_map` records old and new IDs/versions/hashes and mapping state. `structural_changes` retains prior/derived values, evidence, reviewer/time and a replacement representation. |
| Frozen view | `analysis_views`, `analysis_view_sources` and `analysis_view_members` select one evidenced version per native unit for an explicit source/genre/role/unit/time frame and a particular admission decision. Membership checks prevent the wrong source/genre/time/native unit; executive views require verified dated office evidence. Later correction creates another view ID rather than rewriting an earlier freeze. |
| Full-period review | `coverage_cells` keeps all 465 month bins for each frame/source/native genre/role with separate applicability, readable presence, distinct-unit/work counts, pending units, access and inventory completeness. Unknown counts remain null. |
| Later computation | `passages` reserves representation-linked offsets and segmentation-rule lineage; `working_assets` records attributable/physical bytes by component. Neither passages nor computational assets are produced by this adapter. |

Every contract table rejects UPDATE and DELETE with explicit SQL triggers. Identical replay is idempotent; changed immutable facts require new assertion/metadata/content/decision rows. Pending date/identity evidence can resolve through a new metadata version. A native-kind/identity correction that changes the core unit must use an evidenced new identity mapping/relation rather than overwrite the original unit. Views count distinct native IDs rather than versions. The admitted-version diagnostic is not a frozen analysis dataset: a comparison must select explicit view members, one version per unit.

## Unit-specific adapters

**Newspaper:** read an explicitly named whole-article ID/version through an indexed projection after old dispositions have been checked. Preserve source URL, canonical/alias URL evidence, original publication precision, title/edition identity, full-body hash and raw/body references. A multi-page article stays one unit; ordered page/column locators are assembly evidence. Issue PDFs, OCR pieces, image wrappers, preview text and version rows do not count as additional complete works. Old explicit pending holds are carried forward until a named resolution supports a new decision. The archived Border Watch ID 5163 and Northern Rivers Times 2022 image-wrapper holds identified in the bounded parent review remain preserved and excluded from any proposed complete-work acceptance.

**Public/community:** namespace native post/reply/question/answer/comment IDs by source and form. Preserve source-declared Australian community evidence separately from author residence, current account self-presentation and historical body authorship. Original Mastodon/native HTML and structurally derived plain text have different hashes. Reposts/boosts, context containers, previews, remote embedded originals and signatures remain typed context/relations, rather than inflate authored-body counts. Account/source keys are not unique citizens or verified independent people. All technical and international holdings remain archived; this contract performs no semantic filtering.

**RAPID parliamentary data:** preserve the deposited source/version and join `paragraph.session_id → session.session_id`, `paragraph.speaker_detail_id → speaker_detail` and debate identifiers to `debate_title` using the actual exported keys, verified from the source schema. Retain `para_id`, `sequence_number`, `speaker_id`, `speaker_detail_id`, `debate_id`, `procedural_unit_number`, `procedural_unit_type`, sitting date/chamber and original/PDF URL. The procedural-unit namespace must be a **session-qualified tuple**, not its unqualified repeated number. A numbered procedural group is not automatically one speaker turn. Reconstruct an utterance only where documented boundaries and speaker continuity support it; otherwise keep that mapping pending. Missing/null speaker details, date-validity mismatches, heading/table/procedural forms and quoted holders retain explicit states. This design does not promote all parliamentary text to executive speech or ordinary-public expression.

**Executive documents/petitions:** use native release/petition IDs and evidenced original date/type, keeping the retrieved body/version independent of historical equality. Australian institutional provenance survives an overseas speech venue. Petition text and ministerial responses are different works; signature counts are context metadata, not individual authored bodies. A real current public response does not prove an archive-wide live API or exact historical inventory.

Published wrappers are preserved but not imported. Package 36 newspaper code dynamically executes package 27/package 25 code; social code reads old absolute paths and owner/scope controls at import time and requires donor SQL. The new contract imports none of those modules. Only explicitly extracted pure format/locator/parser logic may later be ported behind a new source-specific adapter, tested without legacy paths, leases, counters, queues, `coverage >= 2` completion state or source-count scheduling.

## Admission and dispositions

Each record receives **source, identity, publication date, native unit, content, rights and lineage** checks, with separate state/reason/evidence. There is no opaque confidence score. Provenance directness remains relative to the utterance: original news is direct media evidence, and a post is direct evidence of its author's expression even when it reports another claim. Verification does not establish the truth of every source claim.

| Disposition | Trigger and new-view effect |
|---|---|
| `admitted` | All required structural checks support the native unit and intended internal use. The record is available for explicit view selection; it is not topic/affect/fear certified. |
| `context_only` | Verified native container/repost/preview/procedural context remains traceable but does not count as an independently authored article/body/speech. |
| `pending` | Unknown/conflicting source identity, date evidence, native boundary, body mapping, lineage or use rights; includes unresolved inherited holds. Named evidence may resolve the specific record. |
| `quarantine` | A confirmed structural fault, invalid date, unreadable original or hash mismatch. Preserve the original; record the fault and a future correction/replacement link. |
| `restricted` | Evidence denies an operation required for the declared internal use. Preserve the archive/reference and conditions; do not treat it as a content-quality finding. |
| `archive_only` | Evidenced international source context or publication interval outside the fixed Australian frame. Original data retain their historical meaning. |

Unknown redistribution does not block independently supported internal retention/analysis. Conditional/unknown internal rights remain pending; a blanket source licence does not erase item exceptions or authorize public derivative distribution. Confirmed corrections create new immutable representations/mappings. The implemented transform is only exact CRLF→LF, with both hashes and representation links retained; no thresholding, boilerplate deletion, topic exclusion or source suppression occurs.

Original month/year precision is retained as a bounded date interval. Year-only 2025 records may support source presence/year comparisons but do not enter the monthly view. Unbounded month-only September 2026 or year-only 2026 overlaps the cutoff and remains pending. An explicitly evidenced narrower interval may establish eligibility while retaining the original precision. Naive timestamps remain pending for timezone evidence. Neither missing months nor pre-foundation periods become zero expression, and a single source/date observation is not archive completeness.

The current saved candidate stocks remain **8,169 Australian regular article IDs** and separately **45,679 dated community-context bodies**; these are not summed. A small read-only archived-body sample by the coordinator does not certify the exact frozen 8,169-ID membership (the sampled Gippsland table has 11 undisposed candidates versus 10 in the frozen projection). Do not turn a sample into a newly accepted corpus count. Likewise, parliamentary paragraphs, procedural units, utterances, executive releases and authored public bodies cannot share a count denominator. `combine_compatible_counts` rejects mixed native units/role frames or unproved overlapping sets.

Aus.Social's 2026 concentration and InDaily's repeated annual batches remain named inventory/date/pagination/version checks. They are not proof that every corresponding record is faulty, exhausted, climatically relevant or fear-related. An uncertain record is pending individually; source concentration does not impose whole-source quarantine.

## Full-period coverage and historical public expression

The full-period scaffold enumerates **January 1988–September 2026** for every declared source × native genre × role-frame tuple. It preserves readable original presence, applicable-but-unobserved cells, pre-foundation/otherwise evidenced structural inapplicability, date uncertainty, access-blocked cells and unknown applicability. `full_period_cells` starts all observation/count/inventory fields as unknown/null; it never writes zero expression or assumes source existence. Coverage rows are versioned by frame ID. Calendar coverage alone is separate from full eligible-inventory reconciliation, identity/content/rights validation and source/role comparability.

Pooled overall monthly original-text presence may be supported by any eligible dated Australian original in the declared frame, while other roles' cells retain their own missing/unknown states. That does not fill a public-expression gap with parliamentary text or establish a representative three-role comparison. A complete source-inventory claim separately requires reconciliation with known eligible holdings and explicit disposition of date/identity/unit/access uncertainties; monthly presence alone is insufficient. There is no two-work floor, article/passage quota or fear/relevance gate. Readable-presence flags remain descriptive, and intake is not stopped at a count. Unknown/blocked cells limit the corresponding source/role/comparability claim; international pooled counts cannot fill an Australian gap. Minimum analytical windows remain evidence-supported contiguous frames with background/non-hit months, rather than only climate-positive months.

Historical Australian letters, petitions, archival civic submissions and other public expression require their own original work/native-genre, source/date, access and quoted-holder evidence. The explicit `public_letter`, `civic_submission` and `petition` kinds remain separate from modern social forms. They are distinct historical subframes, not renamed modern forum posts or a generic substitute for every public source. Modern platform pre-foundation months remain inapplicable for that platform while the historical public-expression coverage need stays visible at the research-frame level. Parliamentary text cannot fill those public-expression cells. Source-route supplementation must address named full-period gaps under a subsequent bounded scope; the scaffold does not authorize collection.

Existing stocks, recent benchmarks and the current three-row contract check establish no complete 1988–2026 Australian dataset. Current production imports in this task are **zero**. A recent analysis-view mechanism is useful infrastructure but is not the final adequate corpus or a decision to reduce the research interval.
