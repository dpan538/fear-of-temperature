# Project EDA figure brief — 27 September 2026

> **4 October stage clarification:** This eight-figure design and its outputs remain dated snapshots. Future work follows the [fixed cutoff, distribution and source-quality decision](../decisions/2026-10-04-fixed-cutoff-distribution-and-source-quality.md). Current priorities are distribution anomalies and provenance quality; climate-topic validation and interpretation are deferred to analysis and must not become cleaning or progression gates.

## Purpose and evidence contract

Produce **eight distinct, English-language figures** that let Dai assess the current corpus before the next bounded data-completion tranche. This is an acquisition and readiness audit, not a thesis finding. Answer a different question in each figure; do not pad the set with the same counts redrawn as bars, a heatmap and a map.

Use the latest **committed** UK/US/EU/AU source state that can be read safely. US/EU single-writer acquisition may still be running. Record an as-of UTC timestamp, each input file/database and its own checkpoint time in a data manifest. Open databases read-only; do not restart writers, re-import, re-download or mutate collection tables. Where sources are at different checkpoints, mark them as source-specific snapshots rather than a synchronized census. UK/US/EU Works, Items, versions, segments, Guardian article candidates and petitions are different units; never add them into one unexplained total. Count distinct parent IDs for document-level analyses, and preserve source/jurisdiction/genre/date/status.

The source readiness levels are: `enumerated/datable`, `saved original/readable text`, `climate-topic reviewed`, and `comparable role/time measure supported`. Do not equate any level with the next. A missing audit is **unknown**, not zero. The 465/465 pooled government stored-text presence is a temporal acquisition result, not climate relevance or three-role coverage. The early workflow does not use fear as a collection, quality or progression gate; see [AGENTS.md](../../AGENTS.md).

## Visual system

Create one cohesive atlas, not eight unrelated templates. Landscape format, white background, a restrained academic palette and generous margins. Preserve the project's role colors where roles are encoded: policy/government purple, media blue, public teal; use neutral gray for unknown and one warm accent for a documented gap or caution. Use shapes/labels as well as color so grayscale remains intelligible. Distinguish status colors from role colors. Put the main takeaway in a short title and one-sentence caption; put detailed counting rules in a companion methods table rather than crowding the plot. Avoid decorative national flags, word clouds, unverifiable world choropleths and rainbow node graphs. Every figure needs a named numerator, denominator or unit and as-of timestamp where relevant.

Export each figure as PNG (at least 300 dpi at intended size), vector PDF and SVG, with plot source code and figure-specific input CSV/Parquet. Also create a landscape overview/contact sheet and a concise English `INDEX.md` or HTML showing all eight with one-line conclusions and limitations. Inspect every rendered figure at final display size for clipping, overlap, minimum readable text, legend ambiguity and consistent category encodings. For multi-panel plots, check alignment and collisions with the available nature-figure QA workflow. Do not claim a QA pass from source-code checks alone.
