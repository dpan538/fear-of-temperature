# Decision records

Important methodological and engineering decisions will be recorded here rather than changed silently.

Future decision records may cover:

- anchor revisions;
- lexical-family changes;
- query-rule changes;
- source inclusion or exclusion;
- PostgreSQL schema decisions;
- pilot acceptance thresholds;
- data-freeze decisions.

Each record should identify the date, decision, rationale, evidence or constraints, consequences and superseded decisions where applicable.
