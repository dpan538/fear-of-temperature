# Methodology

## Current pipeline

```text
Historical lexical research
        ↓
Voice/source stratification
        ↓
Semantic and provenance validation
        ↓
Canonical lexical/query specification
        ↓
PostgreSQL research database
        ↓
Pilot retrieval and human review
        ↓
Large-scale corpus collection
        ↓
Frequency / search / semantic analysis
```

Later quantitative analysis must preserve the semantic, documentary and source limitations established during research validation. Frequency, retrieval quantity, semantic classification and accepted historical evidence are related but non-equivalent outputs.
